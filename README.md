# REGISTRO DE FRUTAS

Este programa sirve para anotar frutas sin que se repitan en la lista.

## ¿Qué puedes hacer?

1. Agregar una fruta
2. Ver todas las frutas
3. Buscar una fruta
4. Eliminar una fruta
5. Salir

Si intentas agregar una fruta que ya está, el programa te avisa y no la repite.

## Cómo usarlo

1. Instala Python.
2. Descarga el archivo `registro_frutas.py`.
3. Ejecuta en la terminal:

   ```
   python registro_frutas.py
   ```

4. Elige una opción del menú escribiendo el número.

## Ejemplo

```
Elige una opción: 1
Nombre de la fruta: manzana
'Manzana' agregada correctamente.
```
